## Pistes et choix faits
- `one_sample_test` fait (`backend/methods/one_sample_test.py`, tests dans `tests/test_one_sample_test.py`).
- Simulation réelle (graine 42, 500 rép., n = 25, delta 0,5) : puissance de base Student 0,670, Wilcoxon 0,658. Perte sous Cauchy : Student 0,558, Wilcoxon 0,268. Perte de Student sous Student à 2 ddl : 0,318.
- Wilcoxon sous Cauchy (0,268) dépasse 0,25 : `broken_beyond` relevé. Mais 0,30 ne laisse que 0,018 de marge à Student sous Student à 2 ddl (0,318) : choix de 0,29 (marges d'environ 0,02 de chaque côté, soit environ 1 erreur Monte Carlo). À surveiller au test 2 et au test 3.
- `integrate` fait (`backend/methods/integrate.py`, `tests/test_integrate.py`). Chiffres retrouvés : Euler 1,1 % à h = 0, 45 % à h = 0,6, tour complet dès h = 0,9 ; RK4 < 0,1 % partout. RK4 est plafonné à 4000 pas (temps de calcul : Euler à 3e-4 s sur 10 s coûte déjà 0,5 s). Énergie : k = g/L déduit de `rhs`.
- `ols_ci` fait (`backend/methods/ols_ci.py`, `tests/test_ols_ci.py`). Identique à statsmodels (classic, HC3, HAC Bartlett fenêtre 4(n/100)^(2/9), Breusch-Pagan Koenker, levier, Cook) à 1e-9. Simulation n = 150, graine 42 : sain 95 % ; hetero 0,8 classique 79,6 % / HC3 96,6 % / HAC 95 % ; autocorr classique 75 % / HC3 74 % / HAC 87 % ; erreurs exponentielles ou Student à 2 ddl à n = 30 : classique 93,6 % (robuste) ; Breusch-Pagan à n = 30, hetero 0,7 : 18,6 % de p > 0,05. `ols_match` et `ar1` restent à R1 (hypothèses P1).
- Risque alpha sous Cauchy : 1,0 % à n = 25, 1,6 % à n = 200 (le commentaire du YAML disait 1,8 % et 0,4 % : à revérifier avec le vrai moteur).
